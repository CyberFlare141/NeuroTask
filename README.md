# 🧠 NeuroTask

**AI-Powered Task Management System**

---

## 🎯 Objective

Help users organize daily tasks efficiently and use AI to suggest task priorities and deadlines

---

## 📖 Description

**NeuroTask** is an AI-powered task management system designed to  help users organize  and manage their daily work easily . Users can create, update, and track tasks in a simple and user-friendly interface . The system  uses AI to analyze task  details and suggest  priorities and deadlines . It aims to improve productivity and reduce confusion in task planning .

---

## 👥 Target Audience

* Students
* Professionals
* Small teams

---

## 🛠️ Tech Stack

* Backend: Laravel
* Frontend: React.js
* Rendering Method: Client-Side Rendering (CSR)

---

## ✨ Project Features

### ✅ Core Features

* Registration and login system
* Dashboard to view  tasks
* Create, update, delete, and mark tasks as completed
* Task details view with status and deadline
* User-friendly and responsive interface

---

### 🤖 Exclusive Feature (AI Integration)

* AI-based task priority suggestions 
* AI-recommended deadlines based on task description
* AI-generated daily task summary to help users focus on important tasks

---

### 🔐 User Authentication

* JWT-based authentication
* Secure login and logout

---

### 🗂️ CRUD Operations

CRUD operations are implemented for the following entities:

**Users**

* Register
* Login
* Profile management

**Tasks**

* Create new tasks
* Read and view task list and task details
* Update task information
* Delete tasks

---

## 🔗 API Endpoints (Approximate)

### Authentication APIs

* POST  /api/register
* POST  /api/login
* POST  /api/logout
* GET   /api/profile

### Task Management APIs

* GET     /api/tasks
* POST    /api/tasks
* DELETE  /api/tasks/{id}
